# AI Powered Unified Risk & Origination Assistant (AURA)

## Overview
AURA is a database-driven system designed to manage the complete loan lifecycle, including loan application, risk assessment, approval, and audit tracking.  
This module focuses on establishing database connectivity between a front-end form and a MySQL database.

---

## Objective
To connect a web-based interface with a MySQL database and perform insertion of loan application data.

---

## Technologies Used
- Python (Flask) / Node.js
- MySQL Database
- HTML (Front-end)

---

## Database Details
- Database Name: aura_db  
- Table Used: Loan_Application  

---

## Working
- User enters loan details through a web form  
- Backend application connects to MySQL database  
- SQL query is executed to insert the data  
- Confirmation message is displayed  

---

## Execution
Run the backend:

Python:
python aura.py

Node.js:
node aura.js

---

## Access
http://localhost:5000  
or  
http://localhost:3000  

---

## Output
Inserted Successfully  

---

## Result
Database connectivity between front-end and MySQL database was successfully established and loan data was inserted into the AURA system.
